# Ondo (온도)

Ondo는 공예품, 작업 기록, 긴 설명을 천천히 읽는 사람을 위한 프리셋입니다. 대표 서비스는 고려와 조선의 도자를 감상하고 짧은 관찰 기록을 남기는 개인 감상실입니다. 작품 사진의 유약과 윤곽에서 먼저 시선이 머물고, 짙은 갈색의 제목과 본문을 따라 다음 행동을 찾도록 구성했습니다. [샘플 화면 열기](preview/index.html)

## 화면과 정보의 위계

| 화면 | 가장 먼저 읽는 정보 | 다음 행동 |
| --- | --- | --- |
| 전시실 `#home` | 전시 제목과 한 점의 큰 도판을 마주 놓습니다. 도판 아래에 작품명과 시대를 둡니다. | 화살표로 세 도판을 넘기거나 작품 상세로 들어갑니다. |
| 소장품 `#archive` | 같은 열 위치에 작품명·시대를 놓아 형태와 연대를 비교합니다. | 시대를 선택해 목록을 좁힙니다. |
| 상세 `#work/jar` | 전체 사진 옆에서 관찰할 부분을 짚은 뒤 재질과 소장 번호를 읽습니다. | 소장 기관의 원본을 열거나 해당 작품의 기록을 씁니다. |
| 감상실 `#desk` | 살펴본 작품 수, 다음 감상 작품, 최근에 쓴 문장을 확인합니다. | 첫 방문에는 작품을 고르고, 이후에는 기록 목록에서 작품을 다시 엽니다. |
| 입력 `#write/jar` | 작품 선택과 관찰 메모를 한 흐름에 놓고 선택한 도판을 곁에 둡니다. | 내용을 확인한 뒤 이 브라우저에 저장합니다. |
| 설정 `#settings` | 기기·라이트·다크 선택과 포인트 색상 선택을 각각 묶습니다. | 즉시 결과를 보고 기본 설정으로 복원할 수 있습니다. |

## 색상과 테마

라이트 배경은 아이보리 `#F8F4EB`, 주요 글자색은 `#372A24`, 기본 동작은 테라코타 `#9D4231`입니다. 다크는 `#211D19` 바탕과 `#F3E9DA` 글자, 밝은 코랄 `#F2A189`를 조합합니다. 작품 사진은 테마가 바뀌어도 원래 색을 유지합니다. 기본값은 [토큰](tokens.json), 다크에서 달라지는 값은 [테마 파일](themes/dark.json)에 있습니다.

기본 포인트는 테라코타(`clay`), 대체 포인트는 세이지(`sage`)입니다. 설정에서 세이지를 선택하면 `color.accent.base`, `color.accent.hover`, `color.accent.ink`가 각각 `color.sage.base`, `color.sage.hover`, `color.sage.ink`를 따릅니다. 다크 모드에서 세이지 버튼의 기본 바탕은 `#BECE9E`, 강조 바탕은 `#CFDEB2`, 두 바탕 위의 글자는 `#202815`입니다. 배경·본문·오류색은 밝기 테마에서 정합니다. [공통 포인트 색상 규격](../../docs/preset-format.md#교체-가능한-포인트-색상)

## 서체와 배치

- 한글 제목·본문·컨트롤에는 로컬 Pretendard Variable을 사용합니다. 대표 제목은 최대 80px, 본문은 16px에 행간 1.65, 동작 레이블은 14px를 기준으로 합니다. 작품의 영문 표제에는 기기 내장 세리프 이탤릭을 사용합니다. 읽어야 할 본문은 Pretendard로 이어집니다.
- 기본 간격은 4·8·16·24·32·64px입니다. 바깥 폭은 최대 1200px, 입력 및 읽기 열은 최대 640px입니다. 720px 이하에서는 도판과 본문을 세로로 쌓고, 430px 이하의 소장선은 작은 도판과 제목을 나란히 배열합니다.
- 컨트롤 반경은 8px, 사진 모서리는 4px입니다. 얇은 선으로 목록과 단락을 나누고, 설정 결과를 보여주는 표본에만 낮은 그림자를 사용합니다.
- 아이콘은 방향 이동처럼 뜻이 분명한 곳에 씁니다. 화살표 단독 버튼에는 동작 이름을 제공합니다. 소장 목록의 사진은 일부를 확대해 질감을 비교할 수 있고, 상세에서는 작품 전체를 확인할 수 있습니다. 대체 텍스트는 작품의 형태와 무늬를 설명합니다. [에셋 출처와 라이선스](assets/SOURCES.md)

## 컴포넌트와 상호작용

| 요소 | 상태와 피드백 |
| --- | --- |
| 주요 버튼·링크 | 기본 동작은 포인트 바탕과 전용 글자색을 사용합니다. 버튼에 포인터를 올리면 강조색, 누르면 미세한 위치 변화, 키보드 포커스에는 3px 윤곽선이 나타납니다. 일반 링크는 포인터를 올리면 밑줄이 나타납니다. |
| 탐색·필터 | 현재 페이지에는 밑줄과 `aria-current`를, 선택한 시대에는 채운 배경과 `aria-pressed`를 사용합니다. 필터를 바꾼 뒤에도 포커스가 선택 위치에 있고 작품 수를 알립니다. |
| 입력·선택 | 레이블을 항상 표시합니다. 빈 메모 제출 시 안내 문장과 오류 테두리를 표시하고 필드로 포커스를 옮깁니다. 입력하면 오류를 해제하고 남길 수 있는 분량을 확인할 수 있습니다. |
| 설정·복원 | 라디오의 체크 표시로 선택을 확인합니다. 키보드 방향키로 선택할 수 있습니다. 밝기와 포인트가 기본값이면 복원 버튼을 비활성화합니다. |
| 기록 목록 | 빈 상태는 첫 기록으로 가는 행동을 제공합니다. 저장한 내용은 최근 순으로 쌓이며, 상태 안내 영역에서 저장 결과를 읽어 줍니다. |

문구는 “감상 기록 쓰기”, “기록 저장”처럼 결과가 보이는 동사를 사용합니다. 오류에는 고칠 필드와 방법을 함께 씁니다. 한 화면에서 같은 작품은 같은 이름으로 부르고, 영문 표제에는 한글 이름을 함께 제공합니다.

## 접근성과 검증

일반 텍스트는 배경 대비 4.5:1 이상, 큰 텍스트와 컨트롤 식별 경계·포커스는 3:1 이상을 기준으로 합니다. 보조 문구도 본문 기준으로 측정합니다. 오류·선택 상태에는 문장, 체크 또는 밑줄을 함께 사용합니다. 주요 독립 컨트롤의 높이는 44px 이상이며, 모션 감소 설정에서는 전환을 끕니다. [WCAG 텍스트 대비](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) · [비텍스트 대비](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)

정적 서버에서 1440×960과 390×844로 여섯 화면을 열고 기본·다크 테마를 확인했습니다. 두 테마와 두 포인트 조합에서 각 표면의 본문·보조·상태·포인트 텍스트, 주요 버튼의 기본·강조 글자, 컨트롤 경계와 포커스색을 측정했습니다. 측정 조합 중 최소 대비는 텍스트 5.06:1, 경계·포커스 3.44:1입니다. 후속 검토 항목은 실제 스크린리더에서의 기록 작성 흐름과 운영체제별 고대비 모드입니다.

## 실행과 재사용

프로젝트 루트에서 `python -m http.server 4173 --bind 127.0.0.1`로 정적 서버를 열고 `/presets/ondo/preview/`로 이동합니다. 글꼴·사진·스타일은 프리셋 안에서 읽습니다. 기록과 화면 설정은 브라우저의 로컬 저장소에 저장합니다.

웹에서 재사용할 때는 `implementations/web/tokens.css`를 불러옵니다. JSON을 변경한 뒤에는 프로젝트 루트에서 `node presets/ondo/implementations/web/build.mjs`를 실행해 CSS를 갱신합니다. HTML 루트에 `data-theme="dark"`를 지정하면 다크 모드, `data-accent="sage"`를 지정하면 세이지가 적용됩니다. 두 속성을 함께 쓸 수 있습니다. 포인트 속성을 생략하거나 `data-accent="clay"`로 설정하면 현재 밝기의 테라코타를 사용합니다.
